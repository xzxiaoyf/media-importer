# MediaImporter

#### 介绍
SWIFT 程序，完成 IPHONE，IPAD 设备内照片，视频导出到 MAC 电脑。可以按照拍摄日期建立保存目录。

#### 软件架构
软件架构使用SWIFT语言开发，支持在MAC系统上运行，没有签名。


#### 安装教程

1.  解压缩后运行。
2.  xxxx
3.  xxxx

#### 使用说明

1.  ![输入图片说明](%E6%88%AA%E5%B1%8F2026-11-14%2013.19.28.png)
2.  连接 iPhone 到 MAC 电脑，选择信任，连接成功后，软件界面选择连接设备。
3.  选择保存照片的本地目录。
4.   选择保存方式，点击提交按钮开始导出照片。
5.  导出完成后屏幕上有导出日志，在保存目录下有导出日志文件。
